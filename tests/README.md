# تست‌های فرد سی‌ام‌اس

## پیش‌نیازها

- MySQL/MariaDB در حال اجرا با تنظیمات `config.php`
- سرور توسعه روی `127.0.0.1:8765`:

```sh
php -S 127.0.0.1:8765 -t . router.dev.php
```

- برای تست‌های مرورگر: `npm install playwright`

## اجرا

```sh
# پاک‌سازی HTML (۶۲ مورد) — به دیتابیس یا سرور نیازی ندارد
php tests/sanitizer-test.php

# بررسی‌های امنیتی (۳۸ مورد)
php tests/security-test.php

# تست‌های API (۶۴ مورد) — دیتابیس را از صفر می‌سازد
bash tests/api-test.sh

# مسیریابی در هر دو حالت نشانی (۳۰ مورد)
bash tests/routing-test.sh

# تست‌های مرورگر سایت عمومی (۳۴ مورد)
node tests/site-test.mjs

# تست‌های مرورگر پنل مدیریت (۳۵ مورد)
node tests/admin-test.mjs
```

در مجموع ۲۶۳ مورد بررسی می‌شود.

> `api-test.sh` جداول را drop و دوباره نصب می‌کند تا نتیجه تکرارپذیر
> باشد؛ آن را روی دیتابیس واقعی اجرا نکنید.

## پوشش تست‌ها

| بخش | موارد بررسی‌شده |
|-----|------------------|
| احراز هویت | ورود، خروج، رمز اشتباه، محدودیت نرخ، توکن CSRF |
| دسترسی‌ها | جداسازی نقش‌ها؛ نویسنده به کاربران، تنظیمات و محتوای دیگران دسترسی ندارد |
| محتوا | ایجاد، ویرایش، زباله‌دان، بازگردانی، عملیات گروهی |
| پاک‌سازی HTML | ۴۵ نمونه حمله XSS شامل mXSS، پروتکل رمزگذاری‌شده و رویدادهای بدون فاصله |
| آپلود | رد کردن فایل php، polyglot با هدر جعلی تصویر و پاک‌سازی SVG |
| امنیت پایه | پیمایش مسیر، هش رمز، هش توکن، جداسازی نقش‌ها، عدم افشای داده |
| جستجو | هر چهار مسیر جستجو (نوشته، کاربر، دیدگاه، رسانه) |
| سایت عمومی | مسیریابی، SEO، RSS، نقشه سایت، ۴۰۴، ارسال دیدگاه، موبایل |
| مسیریابی | هر دو حالت نشانی تمیز و پرسمانی، برای هاست‌های بدون mod_rewrite |
| پنل مدیریت | تمام صفحه‌ها، ویرایشگر، پوسته تیره/روشن، بدون خطای کنسول |
