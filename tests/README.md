# تست‌های فرد سی‌ام‌اس

## پیش‌نیازها

- MySQL/MariaDB در حال اجرا با تنظیمات `config.php`
- سرور توسعه روی `127.0.0.1:8765`:

```sh
php -S 127.0.0.1:8765 -t . router.dev.php
```

- برای تست‌های مرورگر: `npm install playwright` در ریشه پروژه (پوشه
  `node_modules/` در بسته انتشار نیست و در گیت هم نادیده گرفته می‌شود).

## اجرا

```sh
# پاک‌سازی HTML (۶۲ مورد) — به دیتابیس یا سرور نیازی ندارد
php tests/sanitizer-test.php

# بررسی‌های امنیتی (۳۸ مورد)
php tests/security-test.php

# تست‌های API (۷۳ مورد) — دیتابیس را از صفر می‌سازد
bash tests/api-test.sh

# مسیریابی در هر دو حالت نشانی (۳۰ مورد)
bash tests/routing-test.sh

# سازگاری کوئری‌ها با ONLY_FULL_GROUP_BY (۳۶ مورد)
php tests/sqlmode-test.php

# سازگاری کد جدید با config.php نسخه‌های قدیمی
bash tests/upgrade-test.sh

# مهر ضدکش روی فایل‌های ظاهری (۳۵ مورد)
php tests/cachebust-test.php

# پنل مدیریت روی موبایل
node tests/mobile-test.mjs

# خودترمیمی استایل وقتی مرورگر نسخه کهنه را کش کرده (۴ مورد)
node tests/cache-heal-test.mjs

# تست‌های مرورگر سایت عمومی (۳۴ مورد)
node tests/site-test.mjs

# تست‌های مرورگر پنل مدیریت (۴۹ مورد)
node tests/admin-test.mjs
```

در مجموع ۳۶۶ مورد بررسی می‌شود.

> `api-test.sh` جداول را drop و دوباره نصب می‌کند تا نتیجه تکرارپذیر
> باشد؛ آن را روی دیتابیس واقعی اجرا نکنید.

## پوشش تست‌ها

| بخش | موارد بررسی‌شده |
|-----|------------------|
| احراز هویت | ورود، خروج، رمز اشتباه، محدودیت نرخ، توکن CSRF |
| دسترسی‌ها | جداسازی نقش‌ها؛ نویسنده به کاربران، تنظیمات و محتوای دیگران دسترسی ندارد |
| محتوا | ایجاد، ویرایش، زباله‌دان، بازگردانی، عملیات گروهی |
| پاک‌سازی HTML | ۴۵ نمونه حمله XSS شامل mXSS، پروتکل رمزگذاری‌شده و رویدادهای بدون فاصله |
| آپلود | رد کردن فایل php، polyglot با هدر جعلی تصویر و پاک‌سازی SVG |
| امنیت پایه | پیمایش مسیر، هش رمز، هش توکن، جداسازی نقش‌ها، عدم افشای داده |
| جستجو | هر چهار مسیر جستجو (نوشته، کاربر، دیدگاه، رسانه) |
| سایت عمومی | مسیریابی، SEO، RSS، نقشه سایت، ۴۰۴، ارسال دیدگاه، موبایل |
| مسیریابی | هر دو حالت نشانی تمیز و پرسمانی، برای هاست‌های بدون mod_rewrite |
| حالت SQL | اجرای همه کوئری‌ها زیر ONLY_FULL_GROUP_BY — پیش‌فرض MySQL 5.7/8 که در MariaDB خاموش است |
| سازگاری ارتقا | اجرای کد امروز با config.php نسخه‌های قبلی؛ config.php کاربر در به‌روزرسانی جایگزین نمی‌شود |
| قالب سایت | فهرست قالب‌های نصب‌شده، سوییچ واقعی و رد کردن نام نامعتبر یا پیمایش مسیر |
| موبایل | کشوی نوار کناری، باز و بسته شدن، نبود سرریز افقی |
| مهر ضدکش | مهر هر فایل از زمان تغییر خودش ساخته می‌شود؛ نگاشت مسیرها و عوض شدن مهر پس از ویرایش فایل |
| نشانی‌های قدیمی | صفحه‌های ورودی html به نسخه PHP می‌رسند و توکن بازیابی رمز حفظ می‌شود |
| خودترمیمی کش | اگر مرورگر یا CDN استایل کهنه بدهد، پنل خودش نسخه تازه را می‌گیرد |
| راست‌به‌چپ | موقعیت دستگیره کلیدهای روشن/خاموش در هر دو جهت و هر دو حالت |
| پنل مدیریت | تمام صفحه‌ها، ویرایشگر، پوسته تیره/روشن، بدون خطای کنسول |
