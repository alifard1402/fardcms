# فرد سی‌ام‌اس

یک سیستم مدیریت محتوای فارسی، سبک و بدون وابستگی — با ساختاری شبیه
وردپرس، ساخته‌شده با **PHP 8** و **Vue 3**.

بدون Composer، بدون npm و بدون مرحله build. فایل‌ها را روی هاست
می‌گذارید، نصب‌کننده را اجرا می‌کنید و سایت آماده است.

```
┌─────────────────────────────────────────────────────────────┐
│  سایت عمومی            پنل مدیریت              REST API     │
│  PHP + قالب            Vue 3 (SPA)             JSON         │
│  index.php             admin/                  api/         │
└───────────────────────────┬─────────────────────────────────┘
                            │
              ┌─────────────▼─────────────┐
              │  includes/  — هسته سیستم   │
              │  MySQL / MariaDB (۱۳ جدول) │
              └───────────────────────────┘
```

## قابلیت‌ها

**محتوا**

- نوشته و برگه با پیش‌نویس، بازبینی، انتشار زمان‌بندی‌شده و خصوصی
- برگه‌های تودرتو با والد و ترتیب دلخواه
- دسته‌بندی سلسله‌مراتبی و برچسب با ساخت خودکار
- ویرایشگر بصری با امکان جابه‌جایی به ویرایش HTML
- زباله‌دان با بازگردانی و عملیات گروهی
- فیلدهای سفارشی (postmeta)

**رسانه**

- آپلود چندفایلی با کشیدن و رها کردن
- ساخت خودکار تصویر بندانگشتی با حفظ شفافیت
- بررسی نوع واقعی فایل و پاک‌سازی SVG
- متن جایگزین و توضیح برای هر فایل

**کاربران**

- پنج نقش با دسترسی‌های تفکیک‌شده (جدول پایین)
- ورود با ایمیل یا نام کاربری
- «مرا به خاطر بسپار» با چرخش توکن
- بازیابی رمز عبور با لینک یک‌بارمصرف
- مشاهده و مدیریت دستگاه‌های فعال

**سایت عمومی**

- نشانی‌های تمیز فارسی (`/blog/سلام-دنیا`)
- قالب راست‌به‌چپ با پوسته تیره و روشن
- دیدگاه درختی با بازبینی
- جستجو، آرشیو دسته/برچسب/نویسنده
- خوراک RSS، نقشه سایت XML و robots.txt خودکار
- تگ‌های Open Graph و داده ساخت‌یافته (JSON-LD)
- حالت تعمیر و نگهداری

**پنل مدیریت**

- تک‌صفحه‌ای (SPA) با Vue 3، بدون مرحله build
- پیشخوان با آمار و نمودار انتشار ۳۰ روز گذشته
- فهرست‌ساز ناوبری با پشتیبانی از زیرمنو
- گزارش فعالیت‌ها (audit log)
- تاریخ شمسی و اعداد فارسی در همه‌جا

## پیش‌نیازها

| مورد | حداقل |
|------|-------|
| PHP | ۸.۱ (آزمایش‌شده تا ۸.۴) |
| MySQL / MariaDB | ۵.۷ / ۱۰.۳ |
| افزونه‌های PHP | `pdo_mysql`، `mbstring`، `json`، `fileinfo`، `dom` |
| اختیاری | `gd` برای ساخت تصویر بندانگشتی |
| وب‌سرور | Apache با `mod_rewrite` یا nginx |

## نصب

**۱.** فایل‌ها را روی هاست کپی کنید.

**۲.** تنظیمات دیتابیس را در `config.php` وارد کنید:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'fardcms');
define('DB_USER', 'root');
define('DB_PASS', '');

define('SITE_URL', 'https://example.com');
define('SECRET_KEY', 'یک-رشته-تصادفی-طولانی-و-یکتا');
```

> `SECRET_KEY` را حتماً عوض کنید؛ برای امضای توکن‌ها استفاده می‌شود.

**۳.** نصب‌کننده را باز کنید: `https://example.com/setup.php`

پیش‌نیازها بررسی می‌شود، سپس عنوان سایت و حساب مدیر را می‌سازید.
جداول، دسته‌بندی‌ها، محتوای نمونه و فهرست ناوبری خودکار ساخته می‌شوند.

**۴.** فایل `setup.php` را حذف کنید.

### نصب از خط فرمان

```sh
php setup.php --email=admin@example.com --username=admin \
              --password='RamzeGhavi@1234' --name='مدیر سایت'
```

اگر `--password` را ندهید، یک رمز قوی ساخته و نمایش داده می‌شود.

### تنظیم وب‌سرور

- **Apache** — فایل `.htaccess` آماده است؛ فقط `mod_rewrite` باید فعال باشد.
- **nginx** — از `nginx.conf.example` استفاده کنید.

### نصب در زیرشاخه

نصب در زیرشاخه (مثل `https://example.com/fardcms/`) پشتیبانی می‌شود.
تنها نکته این است که `SITE_URL` باید شامل همان زیرشاخه باشد:

```php
define('SITE_URL', 'https://example.com/fardcms');
```

اگر این مقدار اشتباه باشد، پیوندهای سایت به مسیر نادرست اشاره می‌کنند.

### اگر برگه‌ها باز نمی‌شوند

نشانی‌هایی مثل `/contact` به `mod_rewrite` نیاز دارند. بخشی از هاست‌های
اشتراکی این افزونه را ندارند یا `.htaccess` را نادیده می‌گیرند؛ در آن
حالت صفحه اصلی باز می‌شود اما هر برگه و نوشته خطای ۴۰۴ می‌دهد — که روی
بعضی هاست‌ها به شکل صفحه سفید دیده می‌شود.

فایل `diagnose.php` را در مرورگر باز کنید:

```
https://example.com/fardcms/diagnose.php
```

این صفحه پیش‌نیازها، اتصال دیتابیس، درستی `SITE_URL` و وضعیت مسیریابی
را بررسی می‌کند و می‌گوید کدام نوع نشانی روی هاست شما کار می‌کند.

اگر `mod_rewrite` در دسترس نبود، در پیشخوان به **تنظیمات → پیشرفته**
بروید و **«نشانی‌های تمیز»** را خاموش کنید. از آن پس پیوندها به شکل
`index.php?route=contact` ساخته می‌شوند و سایت بدون `mod_rewrite` کامل
کار می‌کند.

> پس از رفع مشکل، `diagnose.php` را حذف کنید.

می‌توانید تنظیمات را با متغیر محیطی هم بدهید که برای استقرار خودکار
مناسب‌تر است: `FARDCMS_DB_HOST`، `FARDCMS_DB_NAME`، `FARDCMS_DB_USER`،
`FARDCMS_DB_PASS`، `FARDCMS_URL`، `FARDCMS_SECRET`، `FARDCMS_DEBUG`.

## نکات امنیتی

سیستم با فرض «نویسنده نیمه‌معتمد است» طراحی شده — یعنی کسی که اجازه
نوشتن دارد نباید بتواند به مدیر یا بازدیدکننده حمله کند.

| موضوع | راهکار |
|-------|--------|
| SQL Injection | تمام کوئری‌ها prepared با `EMULATE_PREPARES = false`؛ نام ستون و جدول از فهرست سفید |
| XSS ذخیره‌شده | پاک‌سازی با DOM و فهرست سفید عنصر/ویژگی (`includes/sanitizer.php`) |
| XSS بازتابی | فرار دادن تمام خروجی‌ها با `e()`؛ Vue به‌صورت پیش‌فرض فرار می‌دهد |
| CSRF | توکن الزامی روی هر درخواست تغییردهنده (`X-CSRF-Token`) |
| رمز عبور | bcrypt با cost ۱۲ و rehash خودکار در صورت تغییر تنظیمات |
| سرقت نشست | بازسازی session ID پس از ورود، اتصال به اثر انگشت مرورگر |
| توکن‌ها | توکن بازیابی و «مرا به خاطر بسپار» هش‌شده ذخیره و یک‌بارمصرف می‌شوند |
| حمله جستجوی فراگیر | محدودیت تلاش ورود و محدودیت نرخ مستقل برای هر نقطه پایانی |
| آپلود مخرب | فهرست سفید پسوند + بررسی نوع واقعی + `getimagesize()` + پاک‌سازی SVG |
| اجرای فایل آپلودی | `.htaccess` و قواعد nginx اجرای اسکریپت در `uploads/` را می‌بندند |
| افشای اطلاعات | خطاها فقط در گزارش سرور؛ هش رمز و شناسه نشست هرگز در پاسخ API |
| Host header injection | آدرس ایمیل بازیابی از `SITE_URL` ساخته می‌شود، نه هدر `Host` |

پس از نصب:

1. `setup.php` را حذف کنید.
2. `SECRET_KEY` را عوض کنید.
3. HTTPS را فعال و در `.htaccess` هدر HSTS را باز کنید.
4. کاربر دیتابیس را با کمترین دسترسی لازم بسازید.

## توسعه

```sh
# سرور توسعه با نشانی‌های تمیز
php -S 127.0.0.1:8765 -t . router.dev.php

# حالت اشکال‌زدایی (نمایش خطاها، ثبت ایمیل‌ها در storage/mail.log)
FARDCMS_DEBUG=1 php -S 127.0.0.1:8765 -t . router.dev.php
```

### ساخت قالب تازه

پوشه‌ای در `themes/` بسازید و این فایل‌ها را کنار `theme.json` قرار دهید:

| فایل | کاربرد |
|------|--------|
| `index.php` | فهرست نوشته‌ها (اجباری) |
| `single.php` | نمایش یک نوشته |
| `page.php` | نمایش یک برگه |
| `archive.php` | آرشیو دسته، برچسب و نویسنده |
| `search.php` | نتایج جستجو |
| `404.php` | صفحه یافت نشد |
| `header.php` / `footer.php` | بخش‌های مشترک |

توابع در دسترس قالب:

```php
view('post')                    داده‌های صفحه جاری
themePart('header')             گنجاندن یک بخش
themeUrl('assets/style.css')    آدرس فایل قالب (ریشه‌نسبی)
assetUrl('assets/x.css')        آدرس فایل عمومی (ریشه‌نسبی)
siteUrl('blog')                 آدرس مطلق (برای canonical و RSS)
renderMenu('primary')           رندر یک فهرست ناوبری
renderPagination($meta, $url)   صفحه‌بندی
renderComments($comments)       درخت دیدگاه‌ها
renderMetaTags()                تگ‌های SEO و Open Graph
e($text)                        فرار دادن خروجی — همیشه استفاده کنید
jalaliDate('j F Y', $date)      تاریخ شمسی با اعداد فارسی
```

قالب فعال از بخش تنظیمات (`active_theme`) انتخاب می‌شود.

## بدون وابستگی به CDN

Vue و قلم وزیرمتن همراه پروژه ارائه می‌شوند و از هیچ CDN بیرونی خوانده
نمی‌شوند. دلیلش فقط سرعت نیست: دسترسی به Google Fonts در ایران مسدود
است و سایت باید در هر شرایطی درست نمایش داده شود. علاوه بر آن، آدرس IP
بازدیدکنندگان به سرور شخص ثالث فرستاده نمی‌شود.

برای به‌روزرسانی نسخه‌ها `assets/vendor/README.md` را ببینید.
